# Sample reports

These are reference outputs of the AST-SAST analyzer in all supported formats,
generated by scanning the bundled `demo_vuln_app.py` (14 intentional vulnerabilities
across 11 detection rules).

| File                  | Format      | Description                                            |
|-----------------------|-------------|--------------------------------------------------------|
| `report_console.txt`  | Plain text  | Standard console output (ANSI-colour stripped).        |
| `report.json`         | JSON        | Machine-readable findings, one record per finding.     |
| `report.html`         | HTML        | Self-contained dashboard with severity badges.         |
| `report.sarif`        | SARIF 2.1.0 | OASIS interchange format for GitHub / VS Code / Azure. |

Regenerate locally with:

```bash
python cli_scanner.py demo_vuln_app.py \
    --json  sample_reports/report.json \
    --html  sample_reports/report.html \
    --sarif sample_reports/report.sarif
```
